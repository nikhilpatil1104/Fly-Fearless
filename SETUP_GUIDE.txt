PART 0 — GET YOUR API KEYS (do this first, takes ~5 min)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

You need 2 sets of keys. Both are FREE.

── A. SerpAPI (flight data — replaces Amadeus) ───────────────────────────────

  NOTE: Amadeus Self-Service was deprecated in 2026. SkyRisk now uses
  SerpAPI's Google Flights engine instead — real prices, every route, free.

  1. Go to: https://serpapi.com/users/sign_up?plan=free
  2. Sign up with your email — NO credit card required
  3. After signup, go to: https://serpapi.com/manage-api-key
  4. Your API key is shown on that page — copy it
     It looks like: a1b2c3d4e5f6a1b2c3d4e5f6a1b2c3d4e5f6a1b2
  5. This is your SERPAPI_KEY

  Free tier gives you: 100 searches/month
  Every time a user clicks Search = 1 search used
  The flexible-dates price strip = 7 searches used

── B. OpenAI API (GPT-4o chat + boarding pass scanner) ───────────────────────

  1. Go to: https://platform.openai.com/api-keys
  2. Log in or sign up
  3. Click "Create new secret key" → name it "SkyRisk" → Create
  4. COPY THE KEY NOW — it is only shown once
  5. This is your OPENAI_API_KEY (starts with sk-)

  Billing note: GPT-4o costs ~$0.005 per chat message.
  Add $5 credit at: https://platform.openai.com/settings/billing
  The app works without OpenAI — chat just won't get live AI responses.

PART 2 — BACKEND SETUP (FastAPI + Python)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Open Terminal 1. Keep it open the entire time.

── Step 2.1  Navigate to backend ─────────────────────────────────────────────

  cd skyrisk/backend

── Step 2.2  Create a Python virtual environment ─────────────────────────────

  Mac/Linux:
    python3 -m venv venv
    source venv/bin/activate

  Windows (Command Prompt):
    python -m venv venv
    venv\Scripts\activate.bat

  Windows (PowerShell):
    python -m venv venv
    venv\Scripts\Activate.ps1

  You should see (venv) at the start of your prompt. ✓

── Step 2.3  Install Python dependencies ─────────────────────────────────────

  pip install -r requirements.txt

  This installs:
    serpapi        — SerpAPI client (Google Flights)
    fastapi        — web framework
    uvicorn        — ASGI server
    openai         — OpenAI GPT-4o + Vision
    python-dotenv  — reads .env file
    httpx          — async HTTP
    pydantic       — data validation
    python-multipart — file uploads

  Takes 30–60 seconds. When done: "Successfully installed ..." ✓

── Step 2.4  Create your .env file ───────────────────────────────────────────

  Mac/Linux:
    cp .env.example .env

  Windows (Command Prompt):
    copy .env.example .env

  Open .env in any text editor. It looks like this:

    SERPAPI_KEY=your_serpapi_key_here
    OPENAI_API_KEY=sk-your_openai_key_here
    FRONTEND_URL=http://localhost:3000

  Replace each placeholder with your real keys from Part 0:

    SERPAPI_KEY=a1b2c3d4e5f6a1b2c3d4e5f6a1b2c3d4e5f6a1b2
    OPENAI_API_KEY=sk-proj-abc123...
    FRONTEND_URL=http://localhost:3000

  Save the file. ✓

── Step 2.5  Start the backend server ────────────────────────────────────────

  uvicorn main:app --reload --port 8000

  You should see:
    INFO:     Uvicorn running on http://0.0.0.0:8000
    INFO:     Application startup complete.

  Backend running at: http://localhost:8000 ✓

── Step 2.6  Verify the backend works ────────────────────────────────────────

  Open browser → http://localhost:8000
  Should see: {"service":"SkyRisk API","version":"2.0.0","status":"ok"}

  Open browser → http://localhost:8000/docs
  Should see Swagger UI with /api/flights/search, /api/chat/, etc. ✓

  LEAVE THIS TERMINAL OPEN.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

── "ModuleNotFoundError: No module named 'serpapi'" ──────────────────────────

  Your virtual environment is not active. Run:
    Mac/Linux: source venv/bin/activate
    Windows:   venv\Scripts\activate.bat
  Then: pip install -r requirements.txt

── "SERPAPI_KEY is not set" error in backend ────────────────────────────────

  You forgot to create .env or set the key.
    cp .env.example .env
  Open .env and paste your SerpAPI key from serpapi.com/manage-api-key.
  Restart the backend after saving.

── SerpAPI returns "Invalid API key" (401) ──────────────────────────────────

  Your SERPAPI_KEY is wrong. Double-check it at:
    https://serpapi.com/manage-api-key
  Make sure there are no extra spaces or quotes around it in .env.

── SerpAPI quota reached (429) ──────────────────────────────────────────────

  You've used all 100 free searches for the month.
  Options:
    a) Wait until next month (quota resets on billing date)
    b) Upgrade at serpapi.com ($50/mo for 5,000 searches)
    c) The app shows a friendly message and still displays
       static fallback data for demos

── npm install fails ────────────────────────────────────────────────────────

  Try:
    npm install --legacy-peer-deps
  Or clear and retry:
    rm -rf node_modules package-lock.json
    npm install

── Port 3000 or 8000 already in use ─────────────────────────────────────────

  Frontend on different port:
    npm run dev -- --port 3001

  Backend on different port:
    uvicorn main:app --reload --port 8001
  Then update frontend/.env.local:
    NEXT_PUBLIC_API_URL=http://localhost:8001

── OpenAI errors ────────────────────────────────────────────────────────────

  "Insufficient quota" → Add $5 credit at platform.openai.com/settings/billing
  "Invalid API key"    → Regenerate key at platform.openai.com/api-keys
  The app still works without OpenAI — only chat + upload are affected.
